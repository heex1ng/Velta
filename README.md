## 📖 Overview

**Velta** is a command-line toolkit focused on **Minecraft servers, networking and information gathering**.

The tool provides a simple terminal-based interface with multiple modules designed for Minecraft server management, network diagnostics, reconnaissance and other utilities.

```text
Hello user. Welcome to Velta
To view commands type help

velta@user:~$ help
```

---

## ⚡ Features

### 🖥️ `serverinfo`

Retrieve information about a Minecraft server.

```text
serverinfo
```

---

### 🔌 `scanports`

Scan ports on a target host to identify accessible network services.

```text
scanports
```

---

### 🌍 `geoip`

Retrieve geographic and network information associated with an IP address.

```text
geoip
```

---

### 🤖 `bots`

Connect bots to a Minecraft server for testing and automation purposes.

```text
bots
```

> Only use this feature on Minecraft servers where you have permission to connect automated clients.

---

### 🌊 `mcflood`

Minecraft-focused network testing functionality.

```text
mcflood
```

> Intended exclusively for authorized testing environments.

---

### 📡 `ping`

Check network connectivity and latency to a target.

```text
ping
```

---

### 💥 `servercrash`

Minecraft server stress-testing functionality.

```text
servercrash
```

> Only use this feature against servers you own or have explicit authorization to test.

---

### 🔍 `scanhost`

Scan and analyze a target host.

```text
scanhost
```

---

### 🌐 `subdomain`

Enumerate subdomains associated with a domain.

```text
subdomain
```

---

### 📱 `lookup`

Perform information lookups using a phone number.

```text
lookup
```

The module is designed to retrieve available information associated with a given phone number.
